# App icon

The master artwork is `apps/windows/Assets/App-master.png`, generated with the built-in image generation tool. `scripts/build-icon.ps1` converts it to a Windows ICO with 32-bit alpha frames at 16, 20, 24, 28, 32, 36, 40, 48, 64, 96, 128, and 256 pixels, plus the website's 64-pixel icon. The application and NSIS installer share the ICO.

## Generation prompt

Use case: logo-brand. Asset type: production Windows application icon for Voltura Earner, a lean time and earnings tracker. Create ONE beautifully finished, simple modern Fluent-style app icon, square 1024x1024 with genuinely transparent background outside the icon. A confident cobalt-blue rounded square tile, very subtly brighter blue at the upper left and deep blue lower right, containing a single large crisp white dollar symbol with ONE vertical stem and softly rounded terminals. Keep the dollar symbol unmistakable, optically centered, bold and readable down to 16 pixels. Restrained depth in the tile edge only; clean smooth anti-aliased geometry, no sketchiness, no outlines around the white mark. Straight-on orthographic view, no tilt or perspective. Tile fills approximately 88 percent of the canvas with equal transparent padding all around. The symbol fills approximately 60 percent of the tile height. Palette aligns with the existing app's cobalt #245CB4 and white. No text except the dollar symbol, no wordmark, no coins, no clocks, no extra symbols, no busy details, no background scene, no watermark, no cast shadow outside the tile. This is a polished shipping app asset, not an icon sheet or mockup.
