<section class="section details" aria-label="More information">
  <details><summary>Overtime, sleep, and a new day</summary><div class="detail-body"><p>At your daily limit, Earner follows your overtime preference: stop, continue at the normal rate, or use a different overtime rate. Tracking pauses at midnight and when Windows goes to sleep. Open or restart the app when you are ready, then explicitly start tracking. Time spent paused is not counted.</p></div></details>
  <details><summary>Existing Earner users</summary><div class="detail-body"><p>Voltura Earner is a fresh WPF application with its own settings and work history. It does not import or modify the original Earner app's data.</p></div></details>
  <details><summary>Updates and privacy</summary><div class="detail-body"><p>Installed copies can check for signed updates and download them automatically; you choose when to install. Installing an update saves your work and closes Earner; reopen it if you cancel setup. Exit Earner before running a downloaded installer or uninstaller. Portable copies use manual downloads.</p><p>Your work stays on your computer. Update checks contact GitHub, and the standard installer may download the runtime from Microsoft. Read the <a href="https://github.com/voltura/voltura-earner/blob/main/PRIVACY.md">privacy policy</a>.</p></div></details>
